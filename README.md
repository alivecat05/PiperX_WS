# PiperX_WS

- [Calibration](Calibration/README.md) 提供三相机内参读取、机器人基座外参标定和投影验证。
- [HumanCapture](HumanCapture/README.md) 同步录制人类示范的头部和双腕视频。
- [HumanLabel](HumanLabel/README.md) 将 D555 拍摄的人手操作视频转换为双臂 Piper X 的 `action.csv`。
- [PiperCapture](PiperCapture/README.md) 记录双臂主从示教及同步相机画面。
- [PiperX_Teleop](PiperX_Teleop/README.md) 使用 Quest 3 遥操双臂 Piper X。
- [PiperX_GO](PiperX_GO/README.md) 部署 ACT 和 Diffusion Policy 进行双臂控制。
